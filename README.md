# Campus Navigation System

This project was developed as part of a Diploma in Computer Science assignment. It uses a graph structure to represent campus locations and Breadth-First Search (BFS) to find a route between two locations.

## Main Features
- Stores campus locations using a graph
- Connects locations using edges
- Finds routes using Breadth-First Search (BFS)
- Uses a queue to explore locations level by level
- Tracks visited locations to avoid repeated searching
- Uses parent tracking to reconstruct the final route

## Technology Used
- C++

## Algorithm Used
- Breadth-First Search (BFS)
